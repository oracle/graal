# Requirements

This directory contains the requirements that Native Image functional specifications are accepted
against.
A requirement states a property that must remain true across changes, the domain it quantifies
over, the shape of a counterexample, and the evidence that discharges it.

- [JCA Security Provider Requirements](security-providers.md): construction parity, diagnostic
  sufficiency, and the safety properties of
  [§FS-security-providers](../security-providers.md).
